Why Veyla

Built for the latency, not the demo

Every default is the fast one. The AI stages run on the GPU so they do not add frame time, and the shell never renders over the picture.

Lowest latency path

60 fps on the wire, frame buffer 0, present-on-arrival. 30 fps games stay 60 and frame generation keeps the cadence.

DLSS Super Resolution

Clean 1080p upscaled to your display on any RTX card, with the quality preset picked for the machine.

Frame generation

DLSS-G at 2x to 6x on every RTX card, plus a neural renderer for motion smoothing when you want it.

DualSense, fully

Sticks, triggers, touchpad, motion, lightbar, player LEDs, haptics and adaptive triggers where the game uses them.

Six themes

Aurora, Ocean, Emerald, Ember, Rose, Graphite. The accent, the aurora and the control center all follow the choice.

Updates that just land

Checks GitHub at launch, downloads a ~6 MB cumulative patch, verifies every file and reopens itself.

From zero

Three steps and a PIN

No installer, no background service, no console modification.

01

Download and extract

Grab the standalone zip, unpack it anywhere and run veyla.exe. Allow veyla-engine.exe through the firewall when Windows asks.

02

Enable Remote Play

On the PS5: Settings > System > Remote Play > Enable Remote Play. Wired or 5 GHz Wi-Fi on both ends is the difference between fine and forget everything else.

03

Pair once

Open Settings > Pairing, press Discover, select your console and enter the 8-digit PIN from Link Device. Connecting a PSN account is optional.

Questions

The honest answers

Is PS4 supported?

Not yet. Discovery, pairing and input work for PS4, but the video path is HEVC and PS4 Remote Play is H.264. It is the next item on the list.

Do I need a PlayStation account?

Not for playing at home. Pairing on the local network is enough. A PSN account is only for the optional remote login flow.

Which controllers work?

DualSense over USB or Bluetooth, with haptics and adaptive triggers where the game uses them. PS4 pads work too, without the PS5 extras.

Is it free?

Yes. The client is free to download and the source is on GitHub. Updates are cumulative patches of a few megabytes, delivered in the app.

Why does SmartScreen complain?

The builds are not code-signed. Windows may warn about an unknown publisher; choose "More info" and "Run anyway", or build it yourself.

What does it change on my console?

Nothing. It talks to the official Remote Play endpoint the same way the console expects, and it ships no Sony code.
